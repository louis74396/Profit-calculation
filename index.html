Jumia 选品工具中心

Jumia 选品与利润测算工作台

这个首页把 3 个核心页面整合到一起，方便你后续直接放进项目文件夹并上传到 GitHub。使用流程就是：先测算利润，再确认选品，最后统一查看和维护记录。

整合页面数
3 个
推荐使用顺序
测算 → 确认 → 记录
当前入口文件
index.html
页面 01

利润测算器

用于输入成本、重量、竞品价格、佣金率、仓储费和运费等参数，快速判断当前商品是否具备上线价值。

  • 自动换算 CNY / NGN / USD
  • 自动计算利润、利润率、毛利率
  • 支持一键把结果带入选品表单
进入利润测算器
页面 02

选品确认表单

用于补充选品日期、竞品链接、图片链接和备注，把测算结果转成结构化选品记录，便于沉淀与追踪。

  • 自动读取利润测算页草稿
  • 增加必填校验与链接格式校验
  • 保存后自动进入记录页
进入选品表单
页面 03

选品记录页

用于集中查看所有已保存选品，后续可以继续做筛选、修订、删除和复盘，作为本地选品数据库入口。

  • 统一展示已保存记录
  • 支持单条修改和删除
  • 适合作为后续导出与复盘基础
进入记录页

推荐使用流程

1
先做利润测算

先确认售价、佣金、仓储、运费和税后利润，快速筛掉明显不成立的产品。

2
再完成选品确认

补全竞品链接、图片链接、备注和选品日期，把判断过程沉淀成可追踪记录。

3
最后回到记录页管理

统一查看已保存数据，后续可以继续扩展为筛选、导出、复盘和团队协作页面。
